# FOX Inventory 1.5.0

Полный релиз поверх 1.4.1. Основной акцент: целостность учёта и снижение количества лишних действий в интерфейсе.

## Что важно при обновлении

- Требуется обычный `python manage.py migrate` / штатный запуск контейнера с миграциями.
- Добавляется одно поле `EquipmentLoan.previous_state` через миграцию `0016_equipmentloan_previous_state`.
- Новые временные передачи сохраняют состояние оборудования до передачи и восстанавливают его при возврате.
- У уже существующих на момент обновления активных передач снимка состояния нет. При их возврате применяется безопасный fallback: оборудование возвращается на склад без закрепления.
- Раскрывать сохранённый сетевой пароль теперь могут только пользователи с `is_staff=True`.
- База документов и существующие файлы не преобразуются и не переносятся.

## Обратная совместимость

Релиз не удаляет существующие поля и URL. Изменена только защита опасных операций и поведение временной передачи/возврата.
